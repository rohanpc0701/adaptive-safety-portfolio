# Nasr et al. 2024

**"The Attacker Moves Second"**
arXiv 2510.09023
Nasr, Carlini, Sitawarin, Tramer et al.

---

## Core argument

A deterministic safety defense with a fixed policy is a fixed target. An adaptive adversary who can observe outputs can systematically probe the policy's decision boundary and find evasion strategies. Any fixed policy — even an optimal one — is eventually exploitable.

## Relevance to this project

**Motivates [[EXP3 Bandit]]:** if a fixed threshold is a fixed target, an adaptive threshold is harder to target. → [[F5 PAIR Bandit Harder]] validates this empirically.

**Explains [[F2 PG2 Blindspot]]:** PG2's fixed, discoverable blind spot (no jailbreak phrasing → low score) is exactly the kind of fixed target Nasr et al. describe. The [[PAIR Attacker]] exploits it at round 1 every time.

**Motivates PAIR evaluation:** if we claim the cascade is more robust than a single arm, we need to test it against an adaptive attacker — not just a static benchmark.
